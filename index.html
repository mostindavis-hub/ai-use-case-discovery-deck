The discovery loop

Four steps from long list to live use case

Each step has a time-box, an output and a gate question. If you cannot answer the gate question, stay in the step.

Find: build a long list

Days 1-14
What you do

Run the four lenses with five to eight people from marketing, content and experimentation. Write each idea as: who, which job, what outcome.

What you produce

A long list of 15 to 25 candidate use cases, each described in one sentence.

Gate question

Can we describe the job and the outcome in one sentence?

Score: rank what you found

Days 15-30
What you do

Rate every idea on impact, feasibility, data readiness and risk. Plot them on the matrix and challenge the outliers as a group.

What you produce

A ranked shortlist of three, with one clear winner.

Gate question

Does the winner sit in the Start here quadrant?

Test: prove it small

Days 31-60
What you do

Pilot the top use case with three to five users. Agree the baseline first, then compare results every week.

What you produce

A measured pilot: time saved, quality and cost per outcome against the baseline.

Gate question

Did it beat the baseline by the margin we agreed up front?

Scale: make it routine

Days 61-90
What you do

Roll out to the wider team, set review rules, train champions and track return on token every month.

What you produce

A playbook, a prompt library and the next use case drawn from your matrix.

Gate question

Can someone else run it without you in the room?
