# How to discover your next AI use case

An interactive, Optimizely-branded `reveal.js` deck for running a 50-minute workshop on finding and prioritising AI use cases, with a full facilitator talk track.

**Audience:** mixed. **Examples:** marketing, content and experimentation teams. **Outcome:** everyone leaves with one first use case, an owner, a baseline metric and a review date.

## The 8 slides

1. **Title:** a "Spark an idea" card and four path chips (each jumps to its step).
2. **Four discovery lenses:** flip cards for friction, repetition, data and scale.
3. **Four-step path:** find, score, test and scale, each with a gate question.
4. **Readiness check:** five sliders drive a live radar chart.
5. **Payoff calculator:** hours freed, value, spend and return on token.
6. **Priority matrix:** impact vs feasibility, with bubble size showing data readiness or risk.
7. **90-day roadmap builder:** switch milestones on and off and watch plan strength change.
8. **Commitment checklist:** name a first use case and tick six statements.

## How to present

- Open the deck full screen. Move with the arrow keys or the page scroller at the bottom.
- Press **S** for speaker view, which holds a short note for each slide.
- Every interactive element resets when you leave a slide and return, so you can replay freely.
- Bring two real numbers for slide 5 (a team size and weekly hours on one task).
- Follow `TALK-TRACK.md` for timings, the script, and a 30-minute cut.
